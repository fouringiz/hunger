# Телепорт в портал

Ветка `codex/portal-teleport`, база `main` — `9298dd2`.

Порог привязан к тропе: `GATE_D - 18`, на стыке со светящимся полом. Тело сохраняет непрозрачность и направление подхода, вытягивается до 3.8 раза за 0.28 с, исчезает на пике голубой вспышки в 0.34 с. След затухает ещё 0.20 с. Рябь ограничена поверхностью портала. Звук: синтезированный подъём 240→2400 Гц, 0.22 с.

Каждое тело получает отдельное событие. Снимок продолжает анимацию после удаления тела при утечке; боевая смерть до `GATE_D` отменяет событие. Старое красное кольцо утечки скрыто только в отрисовке. Бой, координаты, `GATE_D`, момент утечки и урон не менялись; тест сверяет исходные отпечатки с baseline.json.

## Кадры из настоящего renderer

- До изменения: [старое бледнение](before-approach.webp).
- Одно тело, последовательные стадии одного прохода: [подход](01-approach.webp), [порог](02-threshold.webp), [пик вспышки](03-peak.webp), [след после удаления тела](04-trail.webp).
- Дополнительно: [вытягивание](stretch.webp), [несколько тел](multiple.webp), [общий кадр](whole-map.webp).
- Циклы: [одно тело](single.mp4), [три тела](multiple.mp4).
- [Звуковой образец](portal-cue.wav) синтезирован по фактическим параметрам WebAudio; это не запись звука браузера.

Кадры получены через `tools/capture-organic-world.cjs` и новый `tools/capture-portal-teleport.cjs`. Второй агент просмотрел стадии и общий кадр: визуальных блокеров не отметил, обнаружил случай боевой смерти. После исправления этого случая новые кадры и тесты не запускались: финальная проверка передана пользователю. Последний полный `npm test` до финальной правки прошёл. Проверки в браузере и прослушивание аппаратного выхода не выполнены.

## Команды проверки из корня репозитория

```sh
node tests/portal-entry.cjs
npm test
git diff --check
```

Точечный тест проверяет фактическую непрозрачность отрисовки, направление, координатный порог, однократность, вытягивание, резкое исчезновение, независимые события и голоса, запрет телепорта при боевой смерти и продолжение после утечки.

При желании обновить визуальные материалы (требуется `npm ci`, если зависимости ещё не установлены):

```sh
node tools/capture-portal-teleport.cjs
node tools/preview-portal-cue.cjs
```

Проверить оба видеопрохода, четыре стадии, различимость врагов и звук с включением/выключением mute в игре. После пересъёмки MP4 автоматически не обновляются; последовательности PNG находятся в `reports/generated/portal-teleport/`.
