# Turret — 3D

- Базовая башня линии кинетики (`turret` в прототипе, «Turret / Турель» в паспорте); ветки 4-го уровня — Machine Gun и Rifle.
- `turret_static.glb`, `turret_static_vc.glb` — принятая модель: спаренные стволы на двух боковых пушках, без вращения — узла `barrel_spin_*` у Turret нет, по контракту это нормально. Палитра из `palette.json`, клип `deploy` 1,50 с с выдвижением пушек 6–10/7–11. Экспорт — `tools/blender/export_tower.py`, конфиг `CFG_TURRET`.
- Скрипта полной сборки нет: голова строилась по шагам в чате, код шагов не сохранён. Это нарушение пункта 13 контракта (`docs/art-3d-parts.md`), записанное в issue «Turret и платформа: нет скрипта сборки» (приоритет низкий, повод — только происхождение).
- `legacy/` — частичные скрипты метода, **не пересобирают модель**: `lib_turret.py` (вспомогательные функции головы), `platform_part.py` (детали платформы до склейки и развёртки). Лежат как история.
- `.blend` в репозиторий не кладётся: в рабочем файле есть сцена `REF_turret` с мешами Meshy.
- Старое имя башни в рабочих материалах — Gatling (из раннего концепта); правильное имя — Turret.
