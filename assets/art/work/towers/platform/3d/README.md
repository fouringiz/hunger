# Платформа — 3D

- `platform_mesh.json` — платформа как данные: вершины, полигоны, номера материалов, развёртка (6 596 треугольников, острова совпадают с Turret). Совпадает с платформой `turret_static.glb` с точностью до округления 1e-6.
- Скрипта сборки нет: детали строит `../../turret/3d/legacy/platform_part.py`, а склейка в один меш и развёртка делались по шагам в чате (issue «Turret и платформа: нет скрипта сборки»). До его появления головы берут платформу из этого файла — так у всех башен одна платформа и одна развёртка.
