# Machine Gun — 3D

- `build_machine_gun.py` — полная сборка из примитивов: геометрия, развёртка, палитра, клип `deploy`, проверка пересечений по всем кадрам, экспорт. Читает только `platform/3d/platform_mesh.json` и `palette.json`; референс Meshy не открывает.
- Запуск из корня репозитория: `blender -b --python assets/art/work/towers/machine_gun/3d/build_machine_gun.py`. Около 20 секунд; два запуска дают побайтно одинаковые файлы.
- `machine_gun_static.glb`, `machine_gun_static_vc.glb` — результат сборки.
- Решения, зашитые в скрипт: вариант B (×1,10 по X и Z от кольца), цапфа y −0,20, шесть стволов на ступице без люльки, латунные обоймы и дульные срезы, плотность головы 300 px/м, клип: пушки 6–23/7–24, голова 24–39.
