# Промпт листа видов — common.pylon

Референсы к промпту: 1) `assets/art/work/style/platform-colorref-v1.webp`, 2) фрагмент `blueprints/platform.svg` с этой деталью. Текст — 688 символов, укладывается в лимит 800 на случай инструмента с ограничением.

```
Референс 1 — цвет и материал (олива, графит, тёмная сталь, светлые кромки, лёгкая грязь, тёмные контуры). Референс 2 — блупринт, форма и пропорции строго по нему.
Лист из 5 ортографических видов детали «угловой пилон» на светло-сером фоне, в ряд: спереди, сбоку, сверху, снизу, сзади. Одна камера без перспективы, один масштаб, деталь целиком и одной ширины во всех видах. В пустоте: без основания, пьедестала, земли, тени, подписей, цифр, стрелок.
Низкий восьмигранный пилон: сверху круглая крышка люка с фаской, по граням широкие прямые фаски, швы плит, болты по углам. Стыковочная грань (низ) — ровная плоская. Пропорции 0.22 × 0.22 × 0.12.
Без лиц, людей, животных, текста, логотипов.
```
