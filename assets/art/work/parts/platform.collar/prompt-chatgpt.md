# Промпт листа видов — platform.collar

Референсы к промпту: 1) `assets/art/work/style/platform-colorref-v1.webp`, 2) фрагмент `blueprints/platform.svg` с этой деталью. Текст — 760 символов, укладывается в лимит 800 на случай инструмента с ограничением.

```
Референс 1 — цвет и материал (олива, графит, тёмная сталь, светлые кромки, лёгкая грязь, тёмные контуры). Референс 2 — блупринт, форма и пропорции строго по нему.
Лист из 5 ортографических видов детали «воротник восьмигранный» на светло-сером фоне, в ряд: спереди, сбоку, сверху, снизу, сзади. Одна камера без перспективы, один масштаб, деталь целиком и одной ширины во всех видах. В пустоте: без основания, пьедестала, земли, тени, подписей, цифр, стрелок.
Плоский восьмигранный воротник с круглым сквозным отверстием в центре (около 0,63 ширины), по кромке отверстия ступенчатая фаска, по краю швы и болты; стенка отверстия — ровный цилиндр. Стыковочная грань (низ) — ровная плоская. Пропорции 0.54 × 0.54 × 0.08.
Без лиц, людей, животных, текста, логотипов.
```
