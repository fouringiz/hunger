# Схемы сборки

Схема — источник правды для блупринта (`tools/blueprint-render.py`) и для будущего манифеста сборки в Godot. Поля: `instances[]` — экземпляр детали из `registry.json` с `pos` (x, y в единицах платформы, +Y = вперёд в Blender), `rot` (градусы вокруг вертикали), `z` (высота посадки низа детали от земли), `phase`; `phases[]` — фазы развёртывания со временем в секундах; `notes[]` — договорённости, которые не выражаются числами.
