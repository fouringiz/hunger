# ADR-0001: Целевая платформа — ПК (Steam) с профилем Steam Deck

Статус: принято 2026-10-30
Заменяет: «Mobile-first, Steam-порт второй волной» (паспорт ≤ v2.16, разделы 2 и 8)

## Контекст

Проект проектировался как мобильный TD, но дизайн — глубокая системность,
длинные сессии, читаемые внутриигровые документы — это ПК-аудитория.
На мобильных премиум-TD почти не продаётся, а F2P требует бюджета на закупку
трафика, которого у команды нет. Steam даёт дешёвый тест спроса
(страница + демо → вишлисты) до того, как написана основная игра.

Таргетинг в каноне полностью автоматический (паспорт, раздел 3), игрок только
ставит, улучшает и продаёт постройки — геймпад не ломает ядро, поэтому профиль
Steam Deck стоит дёшево.

## Решение

1. Основная платформа — ПК, дистрибуция через Steam.
2. Steam Deck — обязательный профиль, не отдельный порт. Два ограничения
   действуют с этого дня:
   - никакой критичной для боя информации только по наведению мыши;
   - всё, что влияет на исход боя, управляемо с геймпада.
3. Гейт по майлстоунам: вертикальный срез и демо проверяются на Deck или
   в эмуляции 1280×800 с геймпадом; нечитаемо — чинится до следующего
   майлстоуна. Полная схема геймпада и отметка Deck Verified — перед релизом,
   не раньше.
4. Мобильная версия — отдельный проект после релиза на ПК; решение по ней
   принимается по результатам продаж.
5. Модель монетизации (паспорт, раздел 8) этим ADR не решается: она написана
   под мобильный F2P и пересматривается отдельным решением.

## Что меняется

- Движок: Godot 4 — фаворит по умолчанию; PixiJS + Capacitor и Cocos Creator
  теряют главный аргумент; Defold — запасной вариант.
- Раздел «Мобильный UX» паспорта действует как раздел UX ввода: правило двух
  тапов становится правилом двух кликов, радиальное меню и сейв в миссии
  остаются.
- Раздел 8 паспорта: позиции, которые не живут на Steam (rewarded-реклама,
  VIP, покупка времени), подлежат пересмотру вместе с моделью.
- Новый артефакт: план Steam-страницы (питч одной фразой, содержание тизера,
  срез для демо) — критерий «стоит ли делать дальше».

## Пересмотр

Условий автоматического пересмотра нет. Решение отменяется только новым ADR
со ссылкой на этот и с явным обоснованием.

## Отклонено

- PC-only без Deck: Verified — бесплатная витрина для нишевой игры, а
  ограничения Deck совпадают с хорошим ПК-UX; цена низкая, пока нет ручного
  наведения.
- Проектировать геймпад-интерфейс с первого дня: тормозит прототипирование.
- Мобильная версия «параллельно»: при ПК-дизайне это переделка, а не порт.
- Условие автоматического пересмотра по порогу вишлистов: порог был бы
  выдуман, а не измерен.
