# Скрипты Blender для 3D техники людей

Контракт головы, происхождение моделей и грабли экспорта — в `docs/art-3d-parts.md`; здесь — что лежит и как запускать.

## Версия

**Blender 5.2.** Каждый скрипт в начале проверяет версию и останавливается на любой другой:

```python
import bpy
if bpy.app.version[:2] != (5, 2):
    raise RuntimeError('Blender 5.2 required (tools/blender/README.md), running %s' % bpy.app.version_string)
```

Причина: API анимации и экспортёра glTF меняется между версиями (в 5.x у Action нет `.fcurves` — кривые лежат в `action.layers[].strips[].channelbags[]`). Переход на новую версию — отдельный патч: строка здесь, проверка во всех скриптах, пересборка всех башен и сравнение экспорта с прежним.

## Скрипты

| Файл | Что делает |
|---|---|
| `export_tower.py` | экспорт башни в `<имя>.glb` и `<имя>_vc.glb` по конфигу; проверки контракта и клипа в самом файле, при ошибке файл удаляется |
| `sync_palette.py` | материалы зон ← `assets/art/work/style/palette.json` (таблица `zones`, `emission_strength`) |
| `lib_uv_tower.py` | развёртка головы: нормализация плотности, свой упаковщик в свободное место вокруг островов платформы, проверка растеризацией |
| `check_tower.py` | пересечения и минимальный зазор в позе и по каждому кадру клипа; стыки с перекрытием 2–3 мм задаются списком |

Сборка конкретной башни (`build_<башня>.py`) лежит рядом с её моделью: `assets/art/work/towers/<башня>/3d/`.

Запуск — внутри Blender (через MCP или консоль Python):

```python
exec(open('<repo>/tools/blender/export_tower.py').read())
export(CFG_MACHINE_GUN, vc=False, out='<папка>/')
```

Переменные окружения: `UTD_REPO` — корень репозитория (по умолчанию — текущая папка), `UTD_3D_OUT` — папка экспорта по умолчанию.

## Хук pre-commit

`.githooks/pre-commit` не пускает в коммит:
- пути с сегментом `REF_*`;
- файлы `.blend` и `.blend1` (в них может лежать сцена референса; в репозиторий идут скрипт сборки и экспорт `.glb`);
- файлы Meshy (модели, текстуры, рендеры с `meshy` в имени);
- `.glb`/`.gltf`, внутри которых есть имена `REF_*` или `Mesh_*` (подпись экспорта Meshy) или генератор Meshy.

Включить один раз на клон:

```
git config core.hooksPath .githooks
```

Хук локальный: в клоне без этой настройки он не работает.
